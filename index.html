Synchronisation GitHub

Chaque modification est enregistrée dans un fichier de ton dépôt (dashboard-config.json). Sur n'importe quel appareil, le dashboard recharge ce fichier au démarrage.
Créer le jeton : GitHub → Settings → Developer settings → Fine-grained tokens → Generate. Choisis Only select repositories (ton dépôt seulement) et la permission Contents : Read and write. Le jeton reste uniquement dans ce navigateur (jamais dans le code ni dans la config) : à coller une fois par appareil. Sans jeton, l'appareil est en lecture seule. Pour ne pas retaper propriétaire / dépôt sur chaque appareil, remplis une fois la constante GITHUB en haut du script.

Sauvegarder / restaurer la configuration

Tes positions, favoris, disposition et thème sont gardés dans ce navigateur. Pour les retrouver partout, enregistre-les dans ton fichier HTML : télécharge le HTML configuré, remplace ton fichier (ou celui de GitHub), et ta config s'applique sur n'importe quel appareil.
